📥 Python Downloader CLI Guide

Download high-definition video/audio of any of the 114 Surahs using the included download_bayan.py script!

Download by Surah Name or Number:

python download_bayan.py --surah Kahf
python download_bayan.py --surah Mulk

Download Episode Range (e.g. 1 to 10):

python download_bayan.py --start 1 --end 10

Download MP3 Audio Only:

python download_bayan.py --surah Fatiha --audio-only

List All 114 Surah Mappings:

python download_bayan.py --list-surahs
